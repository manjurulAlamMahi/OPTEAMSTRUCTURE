1 Why do we need a Special / Rapid Team?

The teams have no team leader, only a Project Manager. The Special / Rapid Team fills that gap and handles the work regular teams can't. Each Operations Manager has one, and it does four jobs:

  • Stack Leaders Each member is the Stack Leader for their skill (Laravel, Django, MERN, Flutter, Front End, UI/UX, n8n, AI) across that Operations Manager's teams. They guide developers, keep standards and help when someone is stuck.
  • Important projects Some projects are too important to risk. They need extra care and experienced hands, so they go to the Special Team.
  • Rapid projects Projects with a very short deadline need people who can start right away and deliver fast, without pulling a regular team off its planned work.
  • Code base knowledge When employees leave, their code is often hard to understand. The Special Team reads and analyses that code, keeps the code structure clean and makes sure the next developer can pick it up.

Two SQA members in each Rapid Team check quality before important and rapid projects go out.

2 Why should the teams be structured like this?

My first choice would be fewer teams. But the plan is to keep all the teams for now, so this is the best way to do it: 6 teams, each with one Project Manager, and the current members spread by role so every team can actually work.

  • Better use of people Members are placed where their skill is needed, instead of some teams being full while others are missing whole roles.
  • Every team can work Every team gets at least 2 people in each role, so it has enough members to take on a project from start to finish.
  • No team is held back No team is left short-staffed or waiting on another team, because the gaps are shared out evenly.
  • Room to grow Teams don't have to be complete on day one. Open slots can be hired later, and extra members are kept for the Rapid Teams.

3 Why is the MERN team important?

The MERN team is where we want to focus and grow. That's why it starts as its own separate team from day one.

  • Flutter isn't always enough We already have Flutter, but some projects need React Native. The MERN team covers that and lets us explore it properly.
  • One language for everything Web front end, backend and mobile are all built with JavaScript, so the whole project is managed in one stack.
  • One developer can do it all A MERN developer can work across front end, backend and React Native, which makes the team flexible and easy to plan.
  • Start with one, grow into many We build this one team up step by step. Once it works well, we can create more MERN teams.
4 What will a Project Manager do?

The Project Manager owns their projects from assignment to delivery and handles everything between the client and the team.

  • Core work
    • Client meetings
    • Check the project status
    • Update the project's Google Doc
    • Send and receive project updates
    • Assign tasks to developers based on those updates
  • Project & client management
    • Update the Project Order Sheet / project sheet
    • Check deadlines
    • Check, send and help with client messages
    • Handle everything in the client management system (CMS)

Support messages are the one exception: the PM gives the project story and the Operations Manager writes them (see Work Flow 1).

5 What will an Operations Manager do?

The Operations Manager sees everything the Project Manager sees, across all 3 of their PMs, and handles escalations, cancellations and support messages.

  • Oversight
    • See every client's situation across their 3 PMs
    • Follow the same project work as the PMs: status, updates, deadlines
    • Check with the PMs and step in wherever needed
  • Escalations, cancellations & support
    • Handle escalations
    • Handle cancellation data
    • Ask the PM for the project story, then write the support messages
6 If everyone gets the same KPI value, what about the best performers?

Everyone gets the same share of the delivered value, but good work is still rewarded on top of it.

  • The PM picks them The Project Manager sees everyone's work every day, so they decide who performed best.
  • Extra value A separate performance pool is kept aside from the start. The best performers get extra value from it.
  • Other benefits Instead of extra value, we can also offer something else, or buy something for them as a reward.
  • Why it works The equal share keeps everyone focused on delivery. The extra reward makes sure the people working hardest and best still stand out.
